# Emory Peck — Engineering & Design Portfolio

This static portfolio website was created from `Portfolio(7).pdf`. It uses the original project imagery and text, adapted for a responsive web layout.

## Preview locally

Open `index.html` in a browser. The site has no build step. All images are stored in `assets/`. Google Fonts are optional: offline the site uses system fallbacks.

## Publish with GitHub Pages

1. Sign in to [GitHub](https://github.com) and create a **public repository** called `YOUR-USERNAME.github.io` (replace `YOUR-USERNAME` with your actual GitHub username).
2. Upload **the contents of this folder**, not the folder itself: `index.html`, `styles.css`, `script.js`, `Portfolio.pdf`, and the `assets` folder. You can use **Add file → Upload files**. Commit the files to the `main` branch.
3. Open repository **Settings → Pages**. Under **Build and deployment**, choose **Deploy from a branch**, `main`, `/ (root)`, then **Save**.
4. Visit `https://YOUR-USERNAME.github.io/`. Publication may take a few minutes.

If you prefer a different repository name (such as `portfolio`), your URL will be `https://YOUR-USERNAME.github.io/portfolio/`. Relative asset paths already support this.

## Make changes

- Edit headings, paragraphs, and links in `index.html`.
- Customize fonts, spacing, and colors in `styles.css`.
- Replace or add photos in `assets/` and adjust the matching image `src`.
- Replace `Portfolio.pdf` when you update your downloadable PDF.
- To add a video demonstration, upload the video to YouTube/Vimeo and add a link to its page (the original PDF only provided a video screenshot, not a playable video).
