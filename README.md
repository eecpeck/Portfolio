# Original PDF portfolio on GitHub Pages

This website displays **the exact original portfolio PDF**, without modifying or recreating any pages.

## Publish or replace your existing site

1. Go to your `eecpeck/Portfolio` GitHub repository.
2. Select **Add file → Upload files**.
3. Upload the `index.html` and `Portfolio.pdf` from this folder (not the ZIP).
4. If GitHub asks about files with the same name, replace them with these versions; commit to `main`.
5. Your existing GitHub Pages site at https://eecpeck.github.io/Portfolio/ will display the PDF once GitHub deploys the update.

The old `styles.css`, `script.js`, and `assets/` files are no longer needed (but leaving them won't change this simple page).

Some mobile browsers may choose to open the PDF in a PDF viewer rather than embedded in the page. The PDF itself remains unchanged.
